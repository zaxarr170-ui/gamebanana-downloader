# GameBanana Downloader — Android-порт

Отдельная копия приложения под Android. Оригинал (`../app.py`, `../core.py`,
`../downloader.py`) не тронут.

## Что изменено против десктопной версии

- **Папки данных**: настройки, история, лог и моды пишутся в приватную папку
  приложения (`FLET_APP_STORAGE_DATA`), а не рядом со скриптом.
- **Окно/трей**: `page.window`, `pystray`, `winsound` отключены на Android
  (на десктопе работают как раньше).
- **«Открыть папку»**: на Android файлового менеджера по пути нет, поэтому
  вместо открытия показывается путь к папке (тост).
- **Ссылки**: открываются через `page.launch_url` (системный браузер).
- **Выбор папки/файлов**: обёрнут в try/except — если Android не поддерживает,
  приложение не падает, а показывает сообщение.
- **Стекло**: весь оформление из `app.py` сохранено.

## Сборка APK (на компьютере)

Нужен ПК с Windows/Linux/macOS. На телефоне собрать нельзя.

1. Поставь Python 3.12 и Flet:
   ```
   pip install flet
   ```
2. Перейди в эту папку:
   ```
   cd android
   ```
3. Собери APK:
   ```
   flet build apk
   ```
   Первый запуск сам скачает JDK 17, Android SDK и Flutter SDK — это долго
   (несколько ГБ) и требует интернета.
4. Готовый файл появится в `build/apk/` (например,
   `gamebanana_downloader.apk`).
5. Скинь APK на телефон и установи (разреши «Установка из неизвестных
   источников»).

Если сборка ругается на `py7zr` — он специально закомментирован в
`pyproject.toml`. Просто не включай.

## Ограничения на Android

- **.zip** — работает.
- **.7z** — только если добавить `py7zr` и сборка пройдёт.
- **.rar** — не распакуется: `rarfile` требует системный `unrar`, которого
  на Android нет.
- **Папка модов** — внутри приложения. Путь показывается тостом по кнопке
  «Открыть папку». Достать файлы можно через «Поделиться» в файловом
  менеджере (Android 11+) или через ADB.
- **Трей, полноэкранный режим F11, звук завершения** — только на ПК.

## Быстрая альтернатива без APK

Веб-версия для Termux:

```
pip install flet
flet run --web src/main.py
```

и открыть `http://localhost:8550` в браузере телефона.

## Сборка без компьютера

1. Залей содержимое этой папки (`android/`) в репозиторий GitHub.
2. Открой вкладку **Actions** → **Build APK** → **Run workflow**.
3. Через 20–40 минут скачай готовый APK из артефактов (артефакт — zip,
   внутри `.apk`).

Workflow уже лежит в `.github/workflows/build-apk.yml`. Сборка идёт на
серверах GitHub, компьютер не нужен. Первый запуск долгий: качаются Flutter
и Android SDK.

Важно: файл workflow должен оказаться в корне репозитория, то есть если
репозиторий называется `downloader`, то путь будет
`downloader/.github/workflows/build-apk.yml`.
